Enable Auto-protect?

When enabled, ScamShield reads visible incoming message text on WhatsApp Web and Gmail, masks common sensitive patterns, then sends the masked text to the ScamShield server for analysis. Pattern-based masking can miss personal information.

The extension stores a random install token, hashed-text result cache, and daily counters in this browser. It does not store raw messages.
